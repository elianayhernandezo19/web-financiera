Como leer la matriz

  • Diagonal = 1: cada activo se correlaciona perfectamente consigo mismo. Es la sanidad de la matriz.
  • Verde: correlacion positiva (suben/bajan juntos). Mas oscuro = mas fuerte. Util para detectar redundancia.
  • Rojo: correlacion negativa (cuando uno sube el otro baja). Util para diversificar (ej. acciones y oro).
  • Cerca de 0: no hay relacion lineal. Diversificacion sin compromiso direccional.

Como leer este grafico

  • Cada vela resume un dia de cotizacion: la linea fina muestra el rango (high-low) y el rectangulo el cuerpo (open-close).
  • Verde: el cierre supero a la apertura (dia alcista). Rojo: el cierre fue inferior (dia bajista).
  • Las SMA (medias moviles) suavizan el ruido. Una SMA corta (20) reacciona rapido; una larga (200) muestra la tendencia estructural.
  • Cuando una SMA corta cruza por encima de una larga se llama "golden cross" (senal alcista clasica). El cruce inverso es "death cross".
